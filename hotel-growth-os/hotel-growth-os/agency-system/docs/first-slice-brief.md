# Agency lead-to-delivery — first-slice working brief

**Status:** Working defaults selected 2026-10-06; not launch-approved public copy.

## Working direction

- Separate, Dhaka-based Agency System.
- Audience direction: B2B small and midsize businesses plus B2C/micro-business customers.
- Service direction: web design/build, branding, SEO/content and ongoing care/growth support. Exact packages and inclusions remain to be confirmed.
- Sales remains human-led. No automated outreach or promises about turnaround/results.

## Keep undecided until approved

- Agency name, logo, visual identity, domain and exact CTA.
- Exact service names, package scope, pricing and guarantees.
- Portfolio pieces, client logos, testimonials, performance metrics and case studies. Do not invent or publish these.
- Separate Agency CRM provider, deduplication/upsert rules, data owner, retention period and API scopes.

## Intake and privacy boundary

- The current parser requires explicit permission to respond to an inquiry; marketing opt-in is separate and defaults to false.
- The current application service uses an injected CRM port and has no live provider. Tests use a fake adapter only.
- No real lead data is to be submitted, persisted, emailed or sent to the HGO CRM.
- Before launch, approve consent copy, privacy notice, retention/deletion behavior, monitoring, failure handling and a human response owner.
